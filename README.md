# AtCoder Library (Python)

競技プログラミング（AtCoder）用の自作 Python ライブラリです。

## 構成

| ディレクトリ | 内容 |
| --- | --- |
| `array/` | セグ木・遅延セグ木・BIT・区間管理など |
| `DP/` | bitDP・区間DP |
| `graph/` | ダイクストラ・Union-Find・SCC など |
| `grid/` | imos法・凸包・偏角ソート・格子点など |
| `math/` | 二項係数・素数・拡張ユークリッドなど |
| `serch/` | 二分探索・bit全探索・尺取り法 |
| `tree/` | BFS/DFS・木DP・全方位木DP・トポロジカルソートなど |
| `other_library/` | 標準ライブラリ / sortedcontainers の使い方メモ |
| ルート直下 | フロー（Dinic）・Grundy数・ランレングス圧縮など |
